FAST NAME SEARCH AND DEFERRED FALLBACKS

Build the signed Debug macOS app, then link SearchTests.swift or
SearchResponsivenessTests.swift to its module and discrete.debug.dylib:

    swiftc -swift-version 5 -default-isolation MainActor -module-cache-path /tmp/discrete-swift-cache -target arm64-apple-macos26.5 -parse-as-library -I /tmp/discrete-search-build/Build/Products/Debug tests/SearchTests.swift /tmp/discrete-search-build/Build/Products/Debug/discrete.app/Contents/MacOS/discrete.debug.dylib -Xlinker -rpath -Xlinker /tmp/discrete-search-build/Build/Products/Debug/discrete.app/Contents/MacOS -o /tmp/discrete-search-tests
    /tmp/discrete-search-tests

SearchTests uses fixture candidates and isolated history preferences. It
checks literal/typo/synonym matching, Spotlight predicate syntax, recency
expiry and bounded boosting, archive demotion, package/build exclusions,
cloud paths, deduplication and cancellation.

SearchResponsivenessTests is an opt-in live-index test for this machine's
reported cases. Replace SearchTests.swift in the command above with
SearchResponsivenessTests.swift and choose a different output binary. It
requires ~/Documents and an indexed Linear Algebra textbook PDF. It reports
first-result/final timings, slowest synchronous keystroke and main-loop gaps,
and verifies:
- Documents stays first, ahead of archived copies.
- Linear Algebra returns a textbook PDF first, with no package internals.
- A misspelled title still finds the book, including while editing prior results.
- eigenvalues finds matching PDF contents after the name phase.
- Repeated queries use cached results immediately.
- Actual DiscreteGraphStore typing receives the correct query/results.
- Exiting during an in-flight search never produces stale results.

After installing/restarting the app, verify those same queries in the overlay.
Try typing quickly, backspacing, then immediately entering a different query.
Typing should remain responsive throughout. Name matches should appear first;
PDF/text contents may fill remaining slots after a short idle interval.
